## Project Structure

```
data/                 Song datasets (JSON lyrics collections, Songs.csv)
docs/                 References (embedding model links)
research/             Experiments and ChromaDB setup scripts
  audio_extraction/   Audio feature (chroma/mel) extraction experiments
  chromaFiles/        Generated Chroma database (not tracked)
scripts/              Lyrics collection and model performance comparison
src/
  API/                FastAPI backend + its Dockerfile
                        claudeMain.py = Hugging Face embeddings + Claude summaries (default)
                        geminiMain.py = Gemini embeddings + summaries (legacy)
                        main.py       = Hugging Face only, no summaries (legacy)
  webservice/         Flask frontend + its Dockerfile
docker-compose.yml    Runs the backend and frontend containers together
```

Run scripts from the repository root unless noted otherwise (e.g. `python scripts/lyricsCollector.py`).

## How it works

- **Embeddings (search):** lyrics and search queries are turned into vectors locally with the Hugging Face model `sentence-transformers/all-MiniLM-L12-v2`, and compared in ChromaDB (`lyrics_similarity_collection`, ~10,000 songs). No API key or per-request cost.
- **Summaries:** song summaries are written by Claude through the Anthropic API.
- **Results:** `/query_lyrics` returns 50 songs by default. Pass `n_results` (1–200) to change this, e.g. `/query_lyrics?query=love&n_results=100`.
- **Similarity score:** cosine similarity between the query and the song lyrics, × 100. Scores are relative, not probabilities: strong matches typically land around 40–60.

## Running with Docker (recommended)

Docker runs the app in two containers, so you don't need to install Python, build tools, or `ffmpeg` yourself.

| Container | What it runs | URL |
|---|---|---|
| `api` | FastAPI backend (`claudeMain.py`) | http://localhost:8000/docs |
| `web` | Flask frontend | http://localhost:5000 |

The databases are not stored in the containers. `research/chromaFiles/` and `research/audio_extraction/` are mounted into the `api` container, so data stays on your machine between rebuilds.

### 1. Install Docker

Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Windows, macOS, Linux). On Windows, enable the WSL 2 backend when prompted.

### 2. Build the Chroma database

The database is not tracked in git. Build it once from the repository root (requires the Python setup under [Running without Docker](#running-without-docker)):

```bash
python research/add-to-chroma.py
```

This writes to `research/chromaFiles/`.

For the audio "match a snippet" feature, `research/audio_extraction/audio_features.db` must also exist (generated by `research/audio_extraction/backendproc.py`). Text search and transcription work without it.

### 3. Create a `.env` file

Create `.env` in the repository root (it is gitignored, so never commit it):

```text
ANTHROPIC_API_KEY=your_anthropic_api_key
SPOTIPY_CLIENT_ID=your_spotify_client_id
SPOTIPY_CLIENT_SECRET=your_spotify_client_secret

# Optional: which Claude model writes summaries (default: claude-opus-5-5)
# CLAUDE_MODEL=claude-haiku-5-5
```

- Anthropic API key: [Claude Console](https://console.anthropic.com/). API usage is billed separately from a Claude.ai subscription.
- Spotify Client ID/Secret: [Spotify Developer](https://developer.spotify.com/documentation/web-api).

### 4. Start the app

```bash
docker compose up --build
```

The first build takes several minutes (it downloads PyTorch and the embedding model). Later builds are fast because Docker caches those steps.

Then open http://localhost:5000.

### Useful commands

| Command | What it does |
|---|---|
| `docker compose up --build` | Rebuild images and start. Run this after changing any code, because code is copied into the image. |
| `docker compose up -d` | Start in the background. |
| `docker compose logs -f api` | Follow the backend's logs. |
| `docker compose exec api bash` | Open a shell inside the running backend container. |
| `docker compose stop` | Stop the containers (keeps them). |
| `docker compose down` | Stop and remove the containers (your data in `research/` is kept). |

## Running without Docker

### Prerequisites

#### Python

The AI Similar Content Extractor is a Python base project and you will need The Python version 3.12 specifically for the application to work properly. 

For Windows the installation can be through the Microsoft Store by simply searching for Python and locating the 3.12 version which should be the second option listed in the app store.

#### Build Tools

For this application to successfully install all the needed modules, that you will have to have to download some build tools in order to have access to everything required for the build.

First navigate to this [link](https://visualstudio.microsoft.com/downloads/?q=build+tools) 

This will take you to the download page for Visual Studio Tools, you will select the free download option and follow it's prompts untill you manage to get to the Workload screen where you can select which options you would like to install. You will only need to select one option which is the Desktop development with C++ under the Desktop & Mobile section. Once you have checked this option you may continue to install. This will take a minute.

#### Modules

The required modules are listed in the `requirements.txt` file. To install them, run the following command:

```bash
pip install -r requirements.txt
```

#### Virtual Enviroment

We will need to set up a virtual enviroment before running the code.

`mkdir venv.`
This command will wreate a new directory named venv, and it will hold the virtual environment files, keeping all dependencies isolated.

`cd .\venv\`
This command will move us into the directory we just made.

`python -m venv .`
This command sets up a virtual environment within the venv folder, and this will allow you to install and manage Python packages independently from the global Python installation. This should help to keep the project dependencies organized.

#### Adding items to ChromaDB

First run the script:
`research/add-to-chroma.py`
This script `research/add-to-chroma.py` is responsible for creating a Chroma database, which will hold vectorized embeddings of text data.
They will then be stored in `research/chromaFiles`.

Then you can run the script:
`research/query_embeddings.py`
There is a variable labeled `query_text` where you input the query you want to search for in the database, and you should recieve similar entries based on your query text.

### Running the application

There are three backends. Claude is the default and the one used by Docker; Gemini and the Hugging Face-only backend are kept for reference.

### To use Claude (default)

1. Install the required Python modules, plus the Anthropic SDK:

    ```bash
    pip install -r requirements.txt
    pip install anthropic==2.14.0
    ```

2. Get an API key from the [Claude Console](https://console.anthropic.com/), and a Spotify API Client_ID and Client_Secret from [Spotify Developer](https://developer.spotify.com/documentation/web-api), then set the environment variables.

    On Linux/macOS run:
    ```bash
    export ANTHROPIC_API_KEY='your_anthropic_api_key'
    export SPOTIPY_CLIENT_ID='your_client_id'
    export SPOTIPY_CLIENT_SECRET='your_client_secret'
    ```

    On Windows in a CMD as admin run:
    ```powershell
    setx ANTHROPIC_API_KEY your_anthropic_api_key
    setx SPOTIPY_CLIENT_ID your_client_id
    setx SPOTIPY_CLIENT_SECRET your_client_secret
    ```

3. In the root directory run `python research/add-to-chroma.py` (skip if `research/chromaFiles` is already built)

4. cd in to `src/API/` and run `uvicorn claudeMain:app --reload`

5. In a separate terminal cd in to `src/webservice/` and run `python flaskapp.py`

6. Visit the URL given after running the flask app and you should see the frontend for the application.

### To use Gemini (legacy)

1. Install the required Python modules listed in the `requirements.txt` file:

    ```bash
    pip install -r requirements.txt
    ```

2. Generate an API key from [Google AI Studio](https://aistudio.google.com/app/apikey) and set the environment variable with this key. Also, generate a Spotify API Client_ID and Client_Secret from [Spotify Developer](https://developer.spotify.com/documentation/web-api) and set the environment variables.

    On Linux/macOS run:
    ```bash
    export GEMINI_API_KEY='your_gemini_api_key'
    export SPOTIPY_CLIENT_ID='your_client_id'
    export SPOTIPY_CLIENT_SECRET='your_client_secret'
    ```

    On Windows in a CMD as admin run:
    ```powershell
    setx GEMINI_API_KEY your_gemini_api_key
    setx SPOTIPY_CLIENT_ID your_client_id
    setx SPOTIPY_CLIENT_SECRET your_client_secret
    ```

3. In the root directory run `python research/gemini-add-to-chroma.py`

4. cd in to `src/api/` and run `uvicorn geminiMain:app --reload`

5. In a separate terminal cd in to `src/webservice/` and run `python flaskapp.py`

6. Visit the URL given after running the flask app and you should see the frontend for the application.
